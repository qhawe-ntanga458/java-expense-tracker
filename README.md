# Java Expense Tracker

## About
A beginner Java project that calculates total expenses and the money remaining from a monthly budget.

## Features
- Accepts a monthly budget.
- Records three expenses.
- Calculates total spending.
- Calculates the remaining balance.

## Technologies
- Java
- Java Scanner for user input

## How to Run
Once Java JDK is installed on a personal computer:

1. Open a terminal in the project folder.
2. Compile the program:
javac ExpenseTracker.java
3. Run the program:
java ExpenseTracker

## Learning Goals
- Variables and data types
- User input
- Arithmetic operations
- Console output
